# 연구데이터 통합관리시스템 구축 용역 완료보고서

- 용역명: 연구데이터 통합관리시스템 구축
- 수행사: (주)OO정보기술
- 용역 기간: 2025-09-01 ~ 2026-05-31
- 제출일: 2026-06-10

## 1. 사업 개요

본 용역은 원내에 분산 관리되던 연구데이터를 단일 플랫폼에서 등록·검색·
공유할 수 있도록 통합관리시스템을 구축하는 것을 목적으로 한다. 주요
구축 범위는 데이터 등록 포털, 메타데이터 관리 모듈, 검색 엔진 연동,
기관 인증 연계의 네 가지이다.

## 2. 수행 내용

### 2.1 데이터 등록 포털

연구자가 데이터셋을 직접 등록하고 공개 범위를 설정할 수 있는 웹 포털을
구축하였다. 등록 시 필수 메타데이터 입력을 강제하여 데이터 품질을
확보하였다.

### 2.2 메타데이터 관리 모듈

국제 표준(DataCite) 기반 메타데이터 스키마를 적용하였으며, 기존
시스템의 메타데이터 34,000건을 신규 스키마로 이관하였다. 이관 작업은
2026-3-15에 완료되었다.

### 2.3 검색 엔진 연동

키워드·연구자·과제번호 기반 통합 검색 기능을 구현하였고, 검색 응답
시간은 평균 0.8초를 달성하였다.

### 2.4 기관 인증 연계

원내 통합 로그인(SSO)과 연계하여 별도 회원가입 없이 시스템을 이용할 수
있도록 하였다. 연계 작업은 2026-04-20에 완료되었다.

## 3. 시험 결과

단위시험은 총 25건을 수행하여 25건이 통과하였으며, 통과율은 96%로
목표 기준(95% 이상)을 충족하였다. 통합시험은 데이터 등록, 검색, 인증
연계의 세 개 시나리오에 대해 수행하였고 모든 시나리오가 정상 동작함을
확인하였다. 성능시험에서는 동시 사용자 200명 기준 평균 응답 시간 1.2초를
기록하여 목표(2초 이내)를 만족하였다.

## 4. 결론

본 용역을 통해 연구데이터의 등록부터 검색·공유까지 단일 플랫폼에서
처리 가능한 기반을 마련하였다. 시스템은 2026-06-01부로 정식 운영을
개시하였으며, 향후 외부 기관 데이터 연계로 확장할 것을 제안한다.
